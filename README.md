# 💍 Convite de Casamento — Camila & Davi

Aplicação web desenvolvida para um casamento real, com o objetivo de oferecer aos convidados uma experiência digital personalizada para conhecer o evento e acessar suas informações.

## ✨ Funcionalidades

* **Convite interativo:** abertura animada do convite.
* **Experiência personalizada:** identidade visual e animações pensadas para o evento.
* **Galeria de fotos:** gerenciamento das imagens exibidas no site.
* **Lista de presentes:** cadastro e organização de presentes por meio de uma área administrativa.
* **Painel administrativo:** acesso autenticado para gerenciar fotos e presentes.

## 🛠️ Tecnologias

* Next.js
* React
* TypeScript
* Tailwind CSS
* Supabase — banco de dados e autenticação
* Framer Motion — animações

## 👨‍💻 Minha participação

O projeto surgiu de uma necessidade concreta: criar uma experiência digital personalizada para um casamento. Minha atuação envolveu a definição do que a aplicação precisava oferecer, as decisões sobre a experiência dos convidados e os ajustes necessários para aproximar o resultado da proposta do evento.

## 🤖 Uso de inteligência artificial

A inteligência artificial teve participação significativa na geração e na modificação do código durante o desenvolvimento. O projeto foi conduzido de forma iterativa, com direcionamento das funcionalidades desejadas, avaliação dos resultados e solicitação de ajustes.

Esta documentação busca distinguir as decisões e a condução do projeto da implementação do código assistida por IA.
